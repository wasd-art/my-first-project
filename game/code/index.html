游戏特色

四个方块，四种玩法

每一种方块，都代表一种独特的游戏体验。

自由建造

没有规则限制，没有边界约束，你可以用任何方块搭建任何形状。

稳定世界

每一次进入，世界都在原地等你。你的每一份努力都会被完整保存。

稀有奖励

深入地下，寻找钻石、黄金与红石，每一次挖掘都可能带来惊喜。

红石科技

用红石搭建电路与机关，让你的世界动起来，自动化一切。
